Software as a Service (SaaS): SaaS users only control application configurations.

Q48_CC:
(right) You can migrate all services immediately and discard existing infrastructure to recover investment and increase ROI.

Rationale: Migrating all services instantly and discarding existing infrastructure is not a recommended migration strategy. AWS typically recommends incremental migration strategies (such as rehost, replatform, or hybrid approaches) that allow organizations to continue using existing on-premises resources during the transition.
